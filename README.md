# Sales-Report-Generator-Py
※就職活動用のポートフォリオです。
売上データ（JSON）を読み込み、統計情報の計算と複数形式（CSV / Text / JSON）でのレポート出力を行うPythonツールです。

## 概要
このプロジェクトは、実務での利用を想定した売上データの集計・変換ツールです。
「入力データの正確性の検証」と「実行時のエラーに対する堅牢性」を重視して設計しました。

## 主な機能
- **複数形式出力**: CSV, テキスト, JSONの3形式でレポートを生成。
- **自動統計計算**: 合計、平均、最大、最小売上を自動で算出。
- **データバリデーション**: 入力データの型チェックを行い、不正なデータによるエラーを未然に防止。
- **詳細なエラーログ**: ファイルの有無や権限エラーなどを識別し、ユーザーに分かりやすく通知。

## 技術スタック
- **Language**: Python 3.x
- **Standard Libraries**: `json`, `csv`, `os`, `datetime`
